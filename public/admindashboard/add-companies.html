CSV Column Order (NO HEADER ROW):
  • company_name (Required) - Name of the company
  • company_code (Optional) - Unique company code
  • industry (Optional) - Industry type
  • website_url (Optional) - Company website
  • logo_url (Optional) - Company logo URL
  • visit_date (Required) - Visit date (YYYY-MM-DD format)
  • job_role (Optional) - Job position offered
  • package_offered (Optional) - Salary package in LPA
  • eligibility_criteria (Optional) - Eligibility requirements
  • visit_status (Optional) - Scheduled/Completed/Cancelled/Postponed (default: Scheduled)

Notes:
  • If company doesn't exist, it will be created automatically
  • Empty optional fields should still have commas as placeholders
  • Package offered should be numeric (e.g., 8.5 for 8.5 LPA)
  • No commas inside text fields (use semicolons if needed)
